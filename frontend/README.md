# Frontend Blueprint (Next.js)

Recommended stack:
- Next.js App Router + TypeScript
- Tailwind CSS + shadcn/ui
- Zustand/Redux Toolkit for chat state
- SSE/WebSocket client for streaming tokens

Key pages:
- `/` landing page
- `/chat` AI chat interface (mode toggle, evidence panel, history)
- `/dashboard` admin analytics
- `/docs` product docs
- `/contact` contact form
